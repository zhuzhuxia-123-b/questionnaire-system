
# 问卷系统测试用例与结果

## 1 测试目的

本文档记录问卷系统第一阶段的测试环境、测试步骤、输入数据、预期输出、实际输出和测试结论。

测试范围包括：

- 用户注册、登录和 JWT 认证；
- 问卷创建、列表、发布和关闭；
- 四种题型及其校验规则；
- 题目编辑和删除；
- 条件跳转和循环保护；
- 答卷提交和填写路径；
- 匿名保护和重复提交；
- 答卷快照；
- 整份问卷和单题统计；
- 数据权限和敏感字段保护；
- 前端页面；
- Jest 自动化测试；
- 测试服务器和测试数据库清理。

## 3 测试方法

本项目使用两类测试。

### 3.1 自动化测试

使用 Jest 和 Supertest 对核心 API 流程进行测试。

自动化测试运行在：

```text
http://127.0.0.1:3101
```

使用独立数据库：

```text
questionnaire_system_test
```

自动化测试不会清理开发数据库 `questionnaire_system`。

### 3.2 手工集成测试

使用以下方式进行手工测试：

- Windows PowerShell 的 `Invoke-RestMethod`；
- mongosh 数据库查询；
- 浏览器页面操作；
- 浏览器开发者工具控制台；
- Node.js 语法和模块加载检查。

中文 JSON 请求使用 UTF-8 字节数组发送，避免 Windows PowerShell 的字符编码影响测试结果。

### 5.2 TC-02：注册、登录和 JWT 认证

**测试目标：**

验证注册、登录、密码哈希、当前用户接口和未登录保护。

**测试输入：**

```json
{
  "username": "student01",
  "password": "Test123456!"
}
```

**测试步骤：**

1. 调用注册接口。
2. 使用相同账号调用登录接口。
3. 保存登录响应中的 JWT。
4. 携带 JWT 调用 `/api/auth/me`。
5. 不携带 JWT 再次调用 `/api/auth/me`。
6. 使用错误密码登录。
7. 使用相同用户名再次注册。
8. 查询 MongoDB 中保存的密码字段。

**预期输出：**

- 注册返回 201；
- 登录返回 200 和 JWT；
- `/api/auth/me` 返回当前用户；
- 未携带 JWT 返回 401；
- 错误密码返回 401；
- 重复用户名返回 409；
- MongoDB 保存 bcrypt 哈希；
- 接口不返回 `passwordHash`。

**实际输出：**

```text
当前用户：
id       : 6ad48face781375b19e1e12b
username : student01

未登录状态码：401
{"message":"缺少有效的登录令牌"}

错误密码状态码：401
{"message":"用户名或密码错误"}

重复用户名状态码：409
{"message":"用户名已存在"}

密码检查：
hasPasswordHash : true
bcryptHash      : true
```

注册、登录和当前用户响应均未返回密码哈希。

**测试结果：** 通过。

### 5.5 TC-05：四种题型和 validation 规范化

**测试目标：**

验证单选、多选、文本、数字四种题型，以及不同题型只保存适用的校验字段。

**测试步骤：**

1. 创建单选题。
2. 创建多选题。
3. 创建文本题。
4. 创建数字题。
5. 查询题目列表。
6. 检查顺序、类型、选项和 `validation`。

**测试输入示例：**

多选题：

```json
{
  "type": "multipleChoice",
  "title": "你经常使用哪些学习方式？",
  "validation": {
    "minSelections": 1,
    "maxSelections": 2,
    "integerOnly": false
  }
}
```

文本题：

```json
{
  "type": "text",
  "title": "请简要描述你的学习计划。",
  "validation": {
    "minLength": 2,
    "maxLength": 200,
    "minValue": 0
  }
}
```

数字题：

```json
{
  "type": "number",
  "title": "你每天平均学习多少小时？",
  "validation": {
    "minValue": 0,
    "maxValue": 24,
    "integerOnly": false
  }
}
```

**预期输出：**

- 题目顺序依次递增；
- 选择题生成稳定 `optionId`；
- 单选题不返回无关校验字段；
- 多选题只保留 `minSelections` 和 `maxSelections`；
- 文本题只保留 `minLength` 和 `maxLength`；
- 数字题只保留 `minValue`、`maxValue` 和 `integerOnly`。

**实际输出：**

```text
singleChoice   : True
multipleChoice : True
text           : True
number         : True
```

四种题型均只保留适用的 `validation` 字段，临时测试题已删除。

**测试结果：** 通过。
